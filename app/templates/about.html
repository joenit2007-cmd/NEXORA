Cybersecurity Threat Monitoring & Vulnerability Assessment Platform

NEXORA is an original defensive and authorized offensive security operations platform built with Python 3.13, Flask, SQLAlchemy, Pandas, Scikit-learn, ReportLab, and Nmap. It consolidates intelligent log analysis, local network visibility, authorized port and service assessment, hybrid ML/rule-based phishing detection, centralized alert triage, and executive PDF/CSV reporting into one unified SOC interface.

Log Intelligence

Parses SSH/auth, syslog, and CSV logs passively without execution. Detects failed logins, sliding-window brute-force bursts, password spraying, privilege escalation, and web attack probes.

Authorized Network & Vulns

Restricts scanning strictly to localhost and RFC1918 private lab targets with explicit user confirmation. Uses Nmap (or safe TCP socket fallback) and evidence-based service/HTTP header checks without fabricating CVEs.

Static Phishing Detection

Combines a reproducible Scikit-learn TF-IDF + Logistic Regression model with transparent lexical URL, sender, and social-engineering heuristics. Never visits or fetches submitted URLs.

Ethical & Security Charter

  • Authorized Scope Only: Public IPs, external domains, and wildcard ranges are rejected server-side.
  • Non-Destructive: No exploit payloads, denial-of-service probes, or active credential attacks are implemented.
  • Transparent Reporting: Dashboard KPIs, vulnerability evidence, and ML test metrics reflect genuine computed outputs.
  • Defense in Depth: PBKDF2-SHA256 password hashing, CSRF tokens, strict CSP headers, parameterized ORM queries, and path-traversal guards.
